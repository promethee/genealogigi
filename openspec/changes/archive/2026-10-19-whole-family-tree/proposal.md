## Why

The Tree tab only shows one person's surroundings; there was no way to see everyone at once, and the shared web page had no tree at all.

## What changes

- Tree tab: a new "Everyone (whole family)" view: every person once, one row per generation, partners side by side joined by a partner-coloured segment.
- Shared web page: a Tree view (header switch People/Tree) with the same whole-family chart, clickable boxes, Fit/Actual size, legend, current person marked.
