See the whole picture

A tree that actually looks like your family.

Ancestors above, descendants below, anyone in the middle. Pick a person and the tree redraws around them, with the numbers that matter.

  • Focus on anyone. Their parents, grandparents, children, siblings and partners, counted at a glance.
  • Ancestors, descendants or both in one hourglass. Show siblings with one click.
  • Real relationships. Dashed lines mark step, foster, adoptive or presumed links.
  • It fits your screen. The tree scales to the window instead of making you scroll.
Every life, in order

Open a person. Read their life.

Each person has a card with a timeline built for you: birth, name changes, marriages, the children they had, the places they lived.

  • Names that change. Maiden name, married name, nickname, each with its date. The tree shows “Jeanne Laurent (née Martin)” the way families say it.
  • Honest dates. Only know the year? Or the month? That is fine.
  • Events with other people. Add a marriage or a move and it appears on everyone involved.
  • Portraits. A round photo for each person, or tidy initials until you find one.

Your family, your file

One file. Plain JSON. Forever readable.

Your whole family lives in a single .gigi file that you choose and you keep. Open it in any text editor. Back it up like a photo. Hand it to a cousin. No lock-in, no company in the middle, nothing to cancel.

  • Private by design. No account, no tracking, no upload.
  • Outlives the app. Plain, human-readable JSON.
  • Safe imports. Before anything is replaced, the previous file is saved next to it with the date and a fingerprint. 
// laurent.gigi
{
  "schemaVersion": 1,
  "people": [
    {
      "names": {
        "lastNames": [
          { "value": "Martin",  "kind": "birth" },
          { "value": "Laurent", "kind": "married" }
        ]
      },
      "born": { "birthPlace": "Grenoble" }
    }
  ],
  "relationships": [ /* … */ ]
}

Questions

Good to know.

Is it really free?

Yes. Genealogigi is open source under the MIT license. There is no paid tier, no ads and no account.

Where is my data stored?

In one .gigi file in the folder you choose, on your computer. The app only contacts GitHub, once at start, to ask whether a newer version exists.

Which systems does it run on?

Windows is the main target today. The source is open (Tauri, Vue and TypeScript) if you want to build it elsewhere.

Can I import my existing tree?

You can import a Genealogigi file. Other formats such as GEDCOM are not supported yet.

Can several relatives work on one family?

The file is easy to share, and you can sync it with your own git repository. Real-time collaboration is not built.
