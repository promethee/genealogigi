# Genealogigi

Desktop genealogy tracker for managing ancestry data and visualizing family
relationships. Built with Vue + Deno Desktop.

Named after my grandma, Gigi.

## Status

🚧 Early development — ground work in progress, no releases yet.

## Stack

- **Shell:** [Deno Desktop](https://docs.deno.com/runtime/desktop/)
- **Frontend:** Vue 3 + Pinia + Tailwind CSS
- **Language:** TypeScript
- **Storage:** SQLite
