# Genealogigi

Desktop genealogy tracker for managing ancestry data and visualizing family
relationships. Built with Vue + Deno Desktop.

## Status

Early development — ground-work phase (tooling, scaffolding). Not yet usable.

## Stack

Deno Desktop · Vue 3 · Pinia · Tailwind CSS · TypeScript · SQLite

## Requirements

- Deno (pin TBD — see `deno.json`)

## Install & run

```sh
deno task dev
```
